# 跨论文术语表

这是一份以机器学习与语言模型论文为例的初始术语表，可直接使用，不预设读者身份或既往阅读记录。阅读新论文、建立 §0 前参考本表；其他学科或特殊定义应以论文语境为准。

同一项目内尽量沿用稳定译法。用户已提供术语约定时优先采用该约定；遇到歧义，保留英文并说明具体含义。

## 同根词族与常用术语

同一词族尽量保留可辨认的中文词根。mis-、un-、non- 可能分别表达错误、未完成或否定，需结合原文确定，不能一律译为“未”。下表提供起始译法，不替代语境判断。

| 英文 | 中文 |
| --- | --- |
| align / misaligned | 对齐 / 未对齐 |
| specification / misspecified | 设定 / 设定错误 |
| calibrate / miscalibrated | 校准 / 校准失当 |
| generalization / misgeneralization | 泛化 / 泛化失当 |
| faithful / unfaithful | 忠实 / 不忠实 |
| scalable oversight | 可规模化监督 |
| steerability | 可引导性 |

## 需要区分的概念

- **honest / honesty**：诚实；涉及表达与意图时，核对论文采用的定义。
- **truthfulness**：真实性；通常关注陈述是否符合事实。

这些词在 alignment 类论文中可能同时出现，不应简单视作同义词。

## 可保留英文的名词

下列术语可在正文中保留英文，并在本篇首次出现时说明中文含义。根据读者偏好和学科惯例选择中英文形式，不要求所有论文都包含这些词。

advantage、policy、value function、response、demonstration、prompt、rollout、ratio、clip、metadata、Likert

## 维护规则

- 只记录实际出现在所读论文中、需要复用的术语。首次使用的新译法先列入本篇 §0，无需为开始阅读额外确认整份术语表。
- 需要跨论文积累时，优先在当前阅读项目中维护 `glossary.md`，避免默认修改已安装技能或影响其他项目。项目未指定其他位置时，可保存在 `Papers/glossary.md`；无需积累时保留在本篇即可。
- 只有在用户要求维护技能本身时，才更新这份初始表。若当前环境无法写入文件，在交付内容中列出建议追加项即可。
- 新增词族时，补充本篇出现的派生形式；不同语境确实需要不同译法时，标明适用范围，不强行合并。
- 用户修订译法后，在当前项目术语表中更新并简记原因。已定稿笔记是否同步修改，遵循本次请求。
