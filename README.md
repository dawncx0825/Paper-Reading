# Paper Reading

这是我的论文阅读档案，用来记录读过的论文、阅读后的总结，以及阅读过程中向 AI 提出的所有问题和相关上下文。

我希望留下的不只是最后的结论，还有理解这些结论的过程：哪里没有读懂、为什么提出这个问题、经过哪些解释和追问，以及哪些理解后来得到了纠正。问答记录已经按照论文顺序整理，方便在重读时对照原文，找回当时的思路。

## 如何阅读

每篇论文使用一个独立文件夹，集中保存论文原文、总结和问答记录。需要回顾整体内容时，可以先看总结；需要理解具体段落、公式或实验时，可以结合原文，按论文顺序查阅问答及上下文。

部分文件夹还会保留阅读过程中形成的讲解约定和输出规范，记录对术语、讲解顺序和内容准确性的要求。

## 关于这些记录

总结与问答是个人学习记录，其中包含 AI 辅助解释和讨论。它们反映了阅读过程中的理解，可能仍有疏漏；涉及具体定义、公式和实验结论时，以论文原文为准。发现问题后会继续修订，也欢迎通过 Issue 交流和纠错。
