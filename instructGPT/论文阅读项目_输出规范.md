# 论文阅读项目·输出规范

下次讲解前先读这份。每条规则都来自一次实际出错。

---

## 术语

**同一英文词根，中文必须共享词根。** 前缀 mis- / un- / non- 一律译成该词根的否定式。解释性说法（「错位」「失准」）只能进括注，不能占术语位。

判断标准不是措辞好坏，而是：换了词根之后，论文里依赖这组词的推理还成不成立。

已钉住的词族：

| 词族 | 固定译法 | 拆开会丢什么 |
| --- | --- | --- |
| align / alignment / **mis**aligned / **un**aligned | 对齐 / **未对齐** | alignment tax、§5.2「对齐谁」两处推理会断 |
| specify / specification / **mis**specified | 设定 / **设定错误** | reward misspecification 是「奖励设定错了」，不是另一个缺陷 |
| calibrate / **mis**calibrated | 校准 / **未校准** | 常误译「置信度失准」，和「校准曲线」断开 |
| generalize / goal **mis**generalization | 泛化 / **泛化失当** | 目标泛化失当 vs 能力泛化，靠同根才看得出是同一轴 |
| faithful / **un**faithful | 忠实 / **不忠实** | CoT faithfulness 整条线建立在正反两态上 |
| scale / scaling / **scalable** oversight | 规模化 / **可规模化监督** | 常译「可扩展监督」，与 scaling law 人为断开 |
| steer / steerability | 引导 / 可引导性 | §5.4 就是把 RLHF 接到这条文献线上 |

**专业名词优先直接用英文原文**，只在第一次介绍时顺带给一下大致中文。已确定用英文的：advantage、policy、value function、response、demonstration、prompt、rollout、ratio、clip、metadata、Likert。

**不造新名词。** 论文里没有的词不要发明。已经犯过的：把 RM 和「RM + KL 惩罚」都叫成「打分函数」，指代不稳定，直接制造混乱。论文只有两个词——**RM**（第 2 步训出的 6B 网络）和**奖励**（RM 输出 − KL 惩罚），两者不是一回事。

**新论文的做法：先建 §0 术语对照表，再写正文。** 不能写完正文回头补——一旦同一个词在不同段落已经被译成不同的词，再统一就是大改。

## 讲解顺序

**依赖必须前置。** 讲 A 之前，A 用到的每个量都得已经讲过。出过的最严重的一次：讲 clip 时公式里出现 `A`，写「先当成 reward 读，下一轮讲」——这是用没定义的符号讲定义。正确顺序是：

```
π → ratio → clip
value function → advantage → clip 完整目标函数
```

**不出现未定义的符号。** 如果一个公式需要还没讲的量，就不写这个公式，先去讲那个量。

**一轮一个概念，讲完停住。** 不预告下一个、不为下一个铺垫。「一个容易漏的点」这种标题是从讲解者视角写的——对他来说是补充细节，对读者是又冒出两个没见过的词。

**不在回答纠错问题的同时塞新内容。** 他在确认理解对不对，读完却多了两个不认识的名词。

**不做对比表，除非两边都已经讲过。** 犯过的：讲 clip 时插了一张 clip vs β 的对比表，而 β 当时还没讲。

**注意积压。** 提过名字但没讲内容的东西会堆积（advantage、GAE、ptx 曾同时挂着三个）。哪怕单轮讲得干净，读者也被三个半懂的名词围着。积压到两个以上就该先清账。

**清单要按「他确认懂了没有」写，不是按「我讲过没有」写。**

## 内容边界

**只讲论文里有的。** 论文外的内容不主动加，他问了再说。犯过的：讲 reward hacking 时，五节里有两节是论文里没有的（长度偏置、谄媚），他没问。

**归属要说准。** reward hacking 被塞进「RM 剩余的坑」是归类错误——它是 PPO 的病，RM 只是被利用的对象。归属说错会让人以为它是 RM 训练流程的一部分。

**自纠错一句话说完，不占编号、不展开。** 犯过的：用一个编号段落纠正自己前一轮的措辞，跟他学的东西无关，却占了注意力位。

**数字必须核过 PDF 原文再说。** 犯过的：凭结构惯性说「第 6 节是结论」，而这篇论文根本没有结论章节。

**论文自己的问题要指出来。** 比如 Table 14 里 CNN-DM 和 TLDR 两行 ROUGE-L 数值完全相同（排版错误）、γ 是盯着 SQuADv2 和 DROP 调的而这两个又出现在结果里（调参集与报告集重合）、test set 规模 3,196 只有 Table 9 一处孤证。

## 排版

**讲解优先输出连贯的大段文本。** 不要把内容拆成大量分点和小标题——分点反而难以理解，而且容易把一个完整的论证切碎。

表格只在内容本身是表格时用：数据集清单、超参对照、两个已讲过的概念并排。不要为了「看起来清楚」把叙述性内容塞进表格。

**讲到论文里有的图，把原图从 PDF 裁出来展示。** 作者画的图比文字描述清晰。这篇论文里架构层面只有 Figure 2 一张，其余 Figure 1、3–9 是结果图，Figure 10–12 是标注指南与界面截图，Figure 28 以后是附录消融曲线。

**论文原文可以在侧栏打开**，方便对照。
